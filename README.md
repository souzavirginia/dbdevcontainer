# Agendamento de Consultas

Exercício da disciplina de Banco de Dados: script DDL do contexto "Agendamento de Consultas". O script foi escrito para PostgreSQL e pode ser executado com o SQLTools no VS Code.

## Ambiente de desenvolvimento

O projeto inclui um Dev Container com Python e um banco PostgreSQL. Requer Docker Desktop e a extensão **Dev Containers** no VS Code.

1. Abra a pasta do projeto no VS Code.
2. Pressione `Ctrl+Shift+P` e selecione **Dev Containers: Reopen in Container**.
3. Aguarde a criação dos containers.

## Conexão com o PostgreSQL

Para conectar pelo SQLTools, utilize as configurações do serviço PostgreSQL definidas no arquivo `compose.yaml`.
